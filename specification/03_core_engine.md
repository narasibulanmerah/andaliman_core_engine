# PURPOSE

Andaliman Core Engine merupakan mesin utama yang bertanggung jawab terhadap proses analisis Human Meaning Text (HMT).

Core Engine menerima teks sebagai masukan dan menghasilkan representasi semantik yang terstruktur.

Core Engine tidak menghasilkan keputusan.

Core Engine menghasilkan hasil analisis.

---

# CORE PRINCIPLE

Meaning precedes language.

Relation precedes interpretation.

Context precedes conclusion.

Human remains responsible for meaning.

# 1. TEXT RECOGNITION

Core Engine terlebih dahulu mengidentifikasi jenis teks.

Supported:

- Poetry
- Narrative
- Essay
- Speech
- Government Narrative
- Public Statement
- General Human Meaning Text

---

# 2. SEMANTIC PARSING

Tujuan:

Mengubah teks menjadi unit semantik.

Parser mengidentifikasi:

- Entity
- Symbol
- Image
- Concept
- Emotion
- Narrative Element
- Relation Candidate

Parser tidak melakukan interpretasi.

---

# 3. SEMANTIC FIELD

Semantic Field merupakan representasi hubungan makna.

Semantic Field terdiri dari:

- Meaning Center
- Semantic Pole
- Semantic Relation
- Semantic Tension
- Semantic Movement
- Collapse Candidate

---

# 4. MEANING CENTER

Meaning Center merupakan pusat gravitasi makna.

Seluruh analisis Andaliman berusaha menemukan Meaning Center sebelum melakukan interpretasi.

Apabila Meaning Center belum ditemukan maka interpretasi tidak dilakukan.

---

# 5. SEMANTIC RELATION

Core Engine membangun hubungan antar elemen.

Jenis hubungan:

- Cause
- Contrast
- Echo
- Transformation
- Reference
- Association

Hubungan harus memiliki bukti tekstual.

---

# 6. SEMANTIC TENSION

Core Engine mencari:

- Conflict
- Contradiction
- Ambiguity
- Silence
- Irony
- Emotional Shift

Semantic Tension menjadi dasar pencarian Collapse.

---

# 7. NARRATIVE STRUCTURE

Apabila teks memiliki struktur naratif.

Core Engine mengidentifikasi:

- Opening
- Development
- Turning Point
- Resolution
- Open Ending

---

# 8. HISTORICAL RESONANCE

Core Engine mendeteksi kemungkinan hubungan dengan:

- Sejarah
- Budaya
- Tradisi
- Peristiwa
- Karya lain

Historical Resonance bukan bukti pengaruh.

Ia merupakan kemungkinan hubungan yang harus diberi tingkat keyakinan.

---

# 9. RESIDUAL MEANING

Residual Meaning adalah makna yang tetap bertahan setelah struktur literal selesai dianalisis.

Residual Meaning bukan ringkasan.

Residual Meaning merupakan hasil akhir proses semantik.

---

# 10. EPISTEMIC CLASSIFICATION

Seluruh hasil analisis wajib diklasifikasikan menjadi:

- FACT
- INTERPRETATION
- HYPOTHESIS
- IMAGINATION

Kategori tidak boleh dicampur.

---

# 11. CONFIDENCE

Core Engine memberikan tingkat keyakinan.

- HIGH
- MEDIUM
- LOW

Confidence harus didasarkan pada bukti analisis.

---

# 12. FAILURE CONDITION

Core Engine menghentikan interpretasi apabila:

- Meaning Center tidak ditemukan.
- Bukti tekstual tidak mencukupi.
- Semantic Relation tidak konsisten.
- Confidence terlalu rendah.

Dalam kondisi tersebut sistem memberikan:

INSUFFICIENT SEMANTIC EVIDENCE

bukan spekulasi.
