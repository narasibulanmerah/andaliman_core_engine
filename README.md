# Andaliman Specification (AS-1.0)

Semantic Intelligence Architecture for Human Meaning Text (HMT)

---

## Overview

Andaliman adalah Semantic Intelligence Architecture yang berjalan di atas Large Language Model (LLM).

Andaliman membantu menganalisis Human Meaning Text melalui pendekatan semantik yang terstruktur, konsisten, dan bertanggung jawab.

Andaliman bukan Large Language Model.

Andaliman merupakan spesifikasi yang dapat diimplementasikan pada berbagai model AI.
